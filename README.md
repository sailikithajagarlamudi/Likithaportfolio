# Likhitha's Function Hall Booking System

## Included
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Veg and Non-Veg food menu
- Online hall booking
- Booking ID generation
- Duplicate booking-date protection
- Booking list
- Booking cancellation
- JSON database for simple college demonstration
- Responsive beautiful design

## Run
Install Node.js 18+.
Open terminal in this folder and run:

npm install
npm start

Then open http://localhost:3000
